# TransGribator 🍄 — Локальная система транскрибации речи (Whisper)

Легковесное веб-приложение для транскрибации видео и аудио на базе модели **Whisper Large-v3-Turbo** (OpenAI) через **Transformers.js v3** и **ONNX Runtime Web**.

100% клиентский инференс, **без PyTorch**, без тяжелых библиотек и без отправки ваших аудиоданных на внешние сервера.

---

## ⚡ Особенности

- **Флагманское качество:** По умолчанию используется **Whisper Large-v3-Turbo** (OpenAI, ~600 МБ в 4-битном квантовании `q4`). Точность на уровне огромной Large-v3, но скорость выше в 4–6 раз.
- **Работа на CPU и iGPU/NPU:**
  - **WebGPU:** Задействует встроенную графику процессора (Intel Iris Xe / Arc, AMD Radeon 780M/680M) без дискретной видеокарты.
  - **CPU (WASM SIMD):** Многопоточный WebAssembly с векторизацией для любого процессора.
- **Прямое извлечение звука:** Браузерный Web Audio API аппаратно декодирует любые медиафайлы (`.mp4`, `.webm`, `.mkv`, `.avi`, `.mp3`, `.wav`, `.m4a`, `.aac`, `.flac`) в 16 кГц моно Float32 прямо в памяти.
- **Интерактивная Студия:**
  - Видео/аудио плеер с интерактивной формой волны.
  - Клик по любому предложению перематывает медиаплеер на этот таймкод.
  - Поиск с подсветкой совпадений и редактирование текста на лету.
  - Экспорт в **.SRT** (стандартные субтитры с таймкодами), **.TXT**, **.VTT**, **.JSON**.

## 📦 Как перенести на ноутбук (Linux или Windows) через обменник

Вам **не нужно** переносить папку `node_modules` (она весит сотни мегабайт).

Для переноса запакуйте в `.zip`:
1. Папку `dist/` (HTML, JS, CSS, Web Worker и бинарник ONNX WASM)
2. Папку `bin/` (содержит автономные бинарники `server-linux` и `server-windows.exe`)
3. Конфиг `sws.toml` (задаёт правильные заголовки COOP/COEP для WebAssembly SIMD)
4. Файлы запуска `start.sh` (для Linux) и `start.bat` (для Windows)
5. Скрипты `serve.js` и `server.py` (как резервные варианты)

**Общий вес архива для передачи: всего ~40 МБ!**

## 🚀 Запуск на чистом Linux (БЕЗ sudo и БЕЗ установки программ)

На целевой Linux-машине **не требуются права root/sudo**, не нужен Node.js, не нужен Python и не нужны внешние библиотеки:

1. Распакуйте архив на ноутбуке:
   ```bash
   unzip transgribator.zip
   cd transgribator
   ```

2. Запустите:
   ```bash
   chmod +x start.sh bin/server-linux
   ./start.sh
   ```

`start.sh` автоматически запустит встроенный musl-бинарник `bin/server-linux`, который не зависит от версии системной libc и работает из обычной папки пользователя.

Если на машине есть `node` или `python3`, скрипт может использовать и их в качестве резерва:
- `node serve.js`
- `python3 server.py`

3. Браузер откроется автоматически по адресу `http://localhost:8080`.

## 🪟 Запуск на Windows

Просто дважды кликните по файлу:
```
start.bat
```
Скрипт автоматически запустит `bin/server-windows.exe` и откроет браузер на `http://localhost:8080`. Никакого Node.js или Python устанавливать не нужно.

## 💡 Включение WebGPU / NPU в Chromium на Linux

В современных браузерах на Linux WebGPU по умолчанию может быть скрыт за флагом. Чтобы ускорить транскрибацию в 5–10 раз:

1. Откройте в адресной строке Chrome/Chromium:
   ```
   chrome://flags/#enable-unsafe-webgpu
   ```
   Переключите в **Enabled**.
2. Включите поддержку Vulkan:
   ```
   chrome://flags/#enable-vulkan
   ```
   Переключите в **Enabled**.
3. Перезапустите браузер (кнопка Relaunch внизу).

Если WebGPU недоступен — приложение автоматически работает на процессоре через **WASM SIMD**.

## 🔒 Приватность и Офлайн

- При первом выборе модели веса загружаются в защищённое локальное хранилище браузера (`CacheStorage` / `IndexedDB`).
- После первой загрузки модель работает **100% офлайн**, интернет больше не требуется!
- Ваши видео и аудио файлы **никогда не загружаются в сеть** — обработка происходит строго в оперативной памяти вашего ноутбука.
