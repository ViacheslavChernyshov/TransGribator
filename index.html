Запуск на Linux та Windows (Без sudo)

1. Чистий Linux без sudo та без встановлення програм

У проєкт уже вбудовано автономний статичний сервер bin/server-linux (musl libc). Йому не потрібні права root / sudo, не потрібен Node.js, Python чи сторонні бібліотеки!

На чистому Linux достатньо запустити:

chmod +x start.sh && ./start.sh

2. Запуск на Windows

Для Windows у проєкт вбудовано bin/server-windows.exe. Просто двічі клікніть файл: 

start.bat

Браузер відкриється автоматично за адресою http://localhost:8080.

3. Увімкнення WebGPU / NPU на Linux

У Chrome / Chromium на Linux увімкніть апаратне прискорення для максимальної швидкості:

  • chrome://flags/#enable-unsafe-webgpu → Enabled
  • chrome://flags/#enable-vulkan → Enabled

Якщо WebGPU не активовано, модель автоматично працюватиме на всіх ядрах процесора через WASM SIMD.
